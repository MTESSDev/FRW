[Voir la documentation de l'outil de déploiement Azure DevOps](https://marketplace.visualstudio.com/items?itemName=MTESS.mtess-frw-deploiement)

## ⚠️ Important

Le nom du formulaire doit être **strictement identique** au nom du répertoire qui le contient.

✅ Correct

```text
3003/
└── 3003.v1.transmission.yml
└── 3003.v1.bind.yml
└── 3003.v1.form.yml
```

❌ Incorrect

```text
3003/
└── transmission.yml
└── bind.3003.yml
└── 3003-01.v1.form.yml
```
