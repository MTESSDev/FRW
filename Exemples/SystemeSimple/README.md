# FRW - Exemples de config pour un système "simple" de base

## ⚠️ Important

Le nom du formulaire doit être **strictement identique** au nom du répertoire qui le contient.

✅ Correct

```text
FORMXYZ/
└── FORMXYZ.v1.bind.yml
└── FORMXYZ.v1.form.yml
```

❌ Incorrect

```text
FORMXYZ/
└── bind.yml
└── test.form.yml
```
